# Changelog

Notable changes to the page are recorded here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## 1.0.0 - 2026-10-03

First open source release.

- Pet profile PDF with a photo, details, vaccines, vet, temperament and notes
  for each pet, plus an emergency contact, references and renter's insurance.
- Share links that carry the profile in the URL fragment, without photos.
- Pet addendum PDF with the lease details, optional charges, editable terms and
  a signature block for the landlord and each tenant, all on one page.
- Service and support animals are noted in the addendum and never charged.
- Everything is saved in the browser only, with a way to clear it.
